# 设计规范 —— 信念

## 色彩

| 用途 | 色值 |
|------|------|
| 页面背景 | `#FAF7F2` |
| 面板/浮层 | `#FFFBF5` |
| 主文字 | `#4A4036` |
| 辅助文字 | `#9C9088` |

### 节点颜色（低饱和暖色系）

| 类型 | 色值 | 半径 |
|------|------|------|
| 核心信念 | `#C8A96E` | 16px |
| 附属信念 | `#8BA4BC` | 13px |
| 思维/情绪模式 | `#B8A0C8` | 12px |
| 想法/情绪 | `#C4B8B0` | 9px |
| 行为 | `#A0B89A` | 9px |
| 物质现实 | `#B8A898` | 14px |
| 种子/未分类 | `#E8E0D8` | 8px |

### 连线：普通 `rgba(216,204,188,0.5)` / 高亮 `#D4A843`

### 态度光晕：破除(淡琥珀) / 坚定(淡青绿) / 观察(浅灰)

## 字体

- 标题：Noto Serif SC (`font-serif`)
- 正文：Noto Sans SC (`font-sans`)
- 后备：PingFang SC → Microsoft YaHei → sans-serif

## 动画

| 场景 | 时长 | 缓动 |
|------|------|------|
| 浮层/抽屉滑入 | 0.3s | ease-out |
| 聚焦切换 | 0.3s | ease |
| 节点呼吸 | 3s | ease-in-out infinite |

## 交互参数

- 长按判定: 600ms（移动 > 8px 取消）
- 拖拽连接距离: 50 world units
- 画布缩放: 0.3x - 2.0x（弹性允许 0.25-2.5）
- 聚焦淡出: 5% 透明度
