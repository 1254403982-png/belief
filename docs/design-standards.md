## 字体

- **标题/品牌**: Noto Serif SC（衬线），`font-serif`
- **正文**: Noto Sans SC（无衬线），`font-sans`
- **后备**: PingFang SC → Microsoft YaHei → sans-serif

## 间距

- 输入框间距：`gap-6` (24px)
- 浮层内边距：`p-6` 或 `p-8`
- 顶部栏：`px-6 py-4`
- 底部输入框距底：`bottom-8` (32px)

## 动画

| 场景 | 时长 | 缓动 |
|------|------|------|
| "信念"浮现 | 1.5s | ease-out |
| 提示文字浮现 | 1.2s (delay 0.8s) | ease-out |
| 登录表单滑入 | 0.8s (delay 0.2s) | ease-out |
| 浮层/抽屉滑入 | 0.3s | ease-out |
| 聚焦模式切换 | 0.3s | ease |
| 节点呼吸 | 3s | ease-in-out infinite |

## 交互规格

- **长按判定时间**: 600ms
- **拖拽节点连接距离阈值**: 30px (屏幕像素)
- **画布缩放范围**: 0.3x - 2.0x
- **聚焦模式淡出透明度**: 5%
- **高亮光晕半径**: 节点半径 + 8px

## 设计原则

1. **留白优先**：能不加的元素坚决不加
2. **文字克制**：能用一个词就不用一句话
3. **过渡柔和**：所有动画都要有 fade/float 感觉，不能硬切
4. **不压迫**：颜色对比度保持温和，不用纯黑纯白
5. **有呼吸感**：浮层用 backdrop-filter blur，半透明
