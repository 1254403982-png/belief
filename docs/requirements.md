# 需求文档 —— 信念 v0.1

## 软件定义

**"信念"** 是一个用于觉察、记录、梳理个人信念系统的 Web 应用。

它帮助用户把"冒出来的想法、情绪、行为模式、现实结果"回溯到背后的信念结构，以一张有纵深感的神经网络图呈现：

```
核心信念 → 附属信念 → 思维/情绪模式 → 想法/情绪 → 行为 → 物质现实
```

## 目标设备

- Windows 电脑（主力，大屏查看网状结构）
- 手机（后期适配，随时输入）
- 形态：Web App（浏览器运行）

## 核心功能

### 1. 随手输入
- 纯文本框，无预分类选项
- 用户只管输入，AI 后台温柔归类
- 输入体验极简，像对空间说话

### 2. 自动/半自动归类
- AI 建议节点类型，用户可确认/修改/忽略
- 不强制分类，可保持"暂时不知道"

### 3. 信念网络展示
- 全屏 Canvas 渲染，2D + 景深层次感
- 左→右流向布局
- 节点：柔和光点/泡泡，低饱和暖色
- 连线：半透明暖灰/柔金

### 4. 可拖拽、缩放、聚焦
- 拖拽平移画布（惯性 + 弹性，60fps）
- 滚轮缩放
- 长按节点进入聚焦模式（高亮链路，其余淡出）

### 5. 节点详情与态度标记
- 点击节点展开详情浮层
- 可标记态度：破除 / 坚定 / 观察
- 双击编辑文字，右键菜单操作

### 6. 信念总览抽屉
- 右侧滑入，三个 Tab：
  - 核心信念树状展开
  - 待破除清单
  - 待坚定清单

### 7. 定期梳理
- 每月长期信念盘点（AI 辅助）
- 每周信念清理（AI 辅助）
- 随时右键标记"待清理"

### 8. "暂时不知道"的包容
- 未分类输入以种子节点存在
- 后续可连接、可归类

## 设计风格

- **极简、温暖、安全、留白、柔和、有呼吸感**
- 背景：暖白/米白 `#FAF7F2`
- 节点：淡金、雾蓝、浅紫、淡绿等低饱和暖色
- 气质：像"温柔的镜子"或"意识空间"

## 不想要的东西

- ❌ 复杂标签墙
- ❌ 黑底霓虹
- ❌ 满屏按钮
- ❌ 强 AI 味
- ❌ 心理诊断感
- ❌ 强迫分类
- ❌ 传统表单
- ❌ 丑的脑图方块
