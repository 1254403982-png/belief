# 需求文档 —— 信念

用户随手输入念头，AI 温柔归类，以一张有纵深感的神经网络图呈现：

```
核心信念 → 附属信念 → 思维/情绪模式 → 想法/情绪 → 行为 → 物质现实
```

## 核心功能

1. **随手输入** — 纯文本框，无预分类，AI 后台归类
2. **自动/半自动归类** — AI 建议类型，用户可确认/修改/忽略
3. **信念网络展示** — 全屏 Canvas，左→右流向，柔和光点+半透明连线
4. **可拖拽/缩放/聚焦** — 拖拽平移(惯性+弹性)、滚轮缩放、长按聚焦链路
5. **节点详情** — 点击详情浮层、态度标记(破除/坚定/观察)、双击编辑
6. **信念总览抽屉** — 核心信念树、待破除/待坚定清单
7. **定期梳理** — 每月盘点 + 每周清理（AI 辅助）
8. **种子节点** — 未分类输入可后续连接归类

## 不想要

❌ 复杂标签墙 ❌ 黑底霓虹 ❌ 满屏按钮 ❌ 强 AI 味 ❌ 心理诊断感 ❌ 强迫分类 ❌ 传统表单 ❌ 丑脑图方块
