## 本轮调整：个人探索优先（2026-10-10）

- 我的探索：自由书写、按需单问题问询、主动整理；取消先给整套分析再要求确认的流程。
- 原话、问题、草稿、用户改写与整理版本持续保存；旧版会话可继续阅读，保留旧分析快照。
- 节点探索共用同一个面板；入图逐条由用户决定，保留来源，不自动生成层级连线。
- 待办与思考分类分开，旧待办继续显示，用户明确完成后才改变状态。
- JSON 备份覆盖节点、连线、日记、待办和探索记录；当前仍为本地数据。
- 下一步云端账号、数据迁移与同步要求见 `docs/cloud-sync-plan.md`。
